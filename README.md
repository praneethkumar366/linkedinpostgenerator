🚀 LinkedIn Post Generator
A smart, beginner-friendly web app that helps users create professional LinkedIn posts from achievements or certificates — using free, open-source AI models like DistilGPT2.

🔍 Why I Built This
In a world where personal branding matters, many people struggle to write polished LinkedIn posts about their achievements. This tool bridges that gap by using AI to automatically generate tone-customized posts that are ready to share — no writing skills required!

✨ Features
📄 Upload certificates (PDF, JPG, PNG) and extract text using OCR (Tesseract)

💬 Enter achievement text manually

🧠 AI-powered post generation with tone selection (casual, professional, formal)

📋 Copy-to-clipboard functionality

🎨 Beautiful, responsive UI built with HTML, CSS, and JavaScript

✅ No paid APIs – fully local using open-source models

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

Backend: Python, Flask

AI Model: DistilGPT2 from Hugging Face Transformers

OCR: Tesseract

Deployment Ready: Flask App structure, static folder setup
